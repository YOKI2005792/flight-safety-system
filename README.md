# flight-safety-system
AI-powered Flight Safety Risk Prediction and Analytics System with Interactive Dashboards and Model Evaluation
# Flight Safety Risk Prediction System

## Overview
This project is an AI-powered Flight Safety Risk Analysis and Prediction System built using Machine Learning.  
It analyzes aviation data to predict risk levels and provides interactive dashboards for safety insights.

## Features
- Flight risk prediction using trained ML models
- Model comparison and evaluation
- Classification report generation
- Confusion matrix analysis
- Feature importance analysis
- Interactive safety dashboards
- Saved trained models for deployment

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib / Visualization tools
- HTML Dashboards

## Project Structure
- `app.py` – Main application
- `server.py` – Backend server logic
- `flight_safety_system.py` – Core ML implementation
- `predict_new_flights.py` – Prediction script
- `saved_models/` – Stored trained models
- Dashboard HTML files – Interactive visualization
